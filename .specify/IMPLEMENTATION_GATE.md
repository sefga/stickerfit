# Шлюз согласования реализации: 007-pdf-cut-contour-underlay

## 🎯 Задача
Расположить векторный контур реза (CutContour) под растровым изображением стикера в PDF для скрытия от печати с сохранением вектора для плоттера.

## 📋 Требования
- **FR-01**: Векторный контур наклейки `drawSvgPath` записывается в content stream PDF до вызова `drawImage` (underlay z-order).
- **FR-02**: Растровое изображение наклейки с запеченным вылетом ложится поверх контура реза, закрывая его визуально при печати.
- **FR-03**: Метки реза листа и оптические метки совмещения остаются в верхнем слое (поверх растра).
- **FR-04**: При отключенной опции `includeCutContour` векторный контур не добавляется.

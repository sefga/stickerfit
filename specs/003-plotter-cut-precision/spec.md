# Feature Specification: Точная юстировка резки и устранение расхождений печати (Plotter Precision & Bleed Masking)

## 1. Проблема и контекст
При практической резке на плоттерах без авто-оптики (Mimaki CG-61, Roland, китайские плоттеры) на кэрриер-матах выявлены критические источники брака и несоответствия:
1. **Квадратный вывод в PDF:** Генератор PDF вставлял растровое изображение стикера прямоугольником без маскирования формы (`circle` / `rounded`), в результате чего на печать выводились углы квадратного исходника.
2. **Искажение масштаба ядра при Bleed:** При включении вылета `bleedMm` изображение целиком увеличивалось (зумилось), приближая логотипы и надписи к линии ножа, вместо сохранения номинального размера значимой зоны.
3. **Резка реперных меток в SVG:** Оптические метки совмещения экспортировались в SVG как обычные видимые векторные линии. При импорте в плоттерные программы (Easy Cut Studio) плоттер резал не только стикеры, но и кресты меток, повреждая кэрриер-мат плоттера.
4. **Смещение Bounding Box в режиме WYSIWYG:** Easy Cut Studio при импорте SVG без явного контура страницы центрирует или привязывает начало реза по границе объектов (`Bounding Box`), которая меньше страницы А4, из-за чего начало координат $(0,0)$ уплывает.
5. **Отсутствие калибровочных расстояний:** Оператор не знает точного физического расстояния между реперными крестами для проверки линейкой масштаба принтера (100% Actual Size).
6. **Перекрытие зон вылетов при плотной раскладке:** При зазорах менее $2 \times \text{bleedMm}$ вылеты соседних стикеров накладываются друг на друга.

## 2. Пользовательские сценарии (User Stories)

### User Story 1 (US1): Круглая и скругленная форма стикера в печатном PDF
- **Как** печатник/мейкер,
- **Я хочу**, чтобы при выборе круглой или скругленной формы в PDF печаталось изображение с прозрачностью за пределами формы стикера,
- **Чтобы** на бумаге не печатались лишние квадратные углы исходного файла.

### User Story 2 (US2): Безопасный файл резки SVG для плоттера
- **Как** оператор плоттера,
- **Я хочу**, чтобы файл контуров SVG по умолчанию содержал ТОЛЬКО линии реза стикеров, а метки совмещения включались опционально,
- **Чтобы** плоттер не резал кресты меток на моем кэрриер-мате, а в режиме WYSIWYG начало координат четко соответствовало углу листа.

### User Story 3 (US3): Калибровочные расстояния между реперами в интерфейсе
- **Как** пользователь,
- **Я хочу** видеть в интерфейсе точные физические расстояния между центрами меток по X и по Y,
- **Чтобы** проверить отпечаток металлической линейкой и сразу выявить искажение масштаба принтера.

### User Story 4 (US4): Валидация и подсказка по минимальному зазору при вылетах (Bleed)
- **Как** дизайнер наклеек,
- **Я хочу** получать предупреждение, если зазор между стикерами меньше $2 \times \text{bleedMm}$,
- **Чтобы** не допустить наложения фоновых вылетов соседних стикеров друг на друга.

## 3. Функциональные требования (Functional Requirements)

- **FR-001 (PDF Masking):** При формировании PDF растровое изображение стикера маскируется по форме (`circle` / `rounded` с учетом `bleedMm`), сохраняя прозрачный альфа-канал снаружи формы.
- **FR-002 (Bleed Scale Preservation):** При `bleedMm > 0` масштаб центрального контента стикера сохраняется в номинальном размере `widthMm × heightMm`, а наружу продолжается фоновая заливка/вылет.
- **FR-003 (Cut-Only SVG Default):** По умолчанию в файл контура резки SVG экспортируются ТОЛЬКО контуры стикеров `<g id="CutContour">`. Добавлен чекбокс/опция «Включать метки в SVG для плоттера» (по умолчанию выключен).
- **FR-004 (Page Frame in SVG):** В SVG контура резки включается прозрачный базовый прямоугольник страницы `<rect id="PageBoundary" width="..." height="..." fill="none" stroke="none" />` с размерами листа, обеспечивающий фиксацию системы координат в WYSIWYG режиме плоттерных программ.
- **FR-005 (Calibration Distances Display):** При включении меток совмещения в секции «5. Полиграфия и резка» отображается блок с расчетными расстояниями между центрами реперов (для А4 Landscape: 281.0 мм по горизонтали и 194.0 мм по вертикали; для Portrait: 194.0 × 281.0 мм).
- **FR-006 (Bleed Gap Warning):** Если `bleedMm > 0` и `gapX < bleedMm * 2` или `gapY < bleedMm * 2`, в интерфейсе отображается мягкое предупреждение с рекомендацией увеличить зазор до $\ge 2 \times \text{bleedMm}$.
- **FR-007 (Separate Template Export):** Возможность скачать отдельный файл шаблона реперов («Калибровочный шаблон реперов SVG») для вычерчивания ручкой на прозрачной пленке/мате.

## 4. Критерии приемки (Acceptance Criteria)

1. **AC-1:** В сгенерированном PDF круглые стикеры имеют круглую форму без квадратных кромок вокруг.
2. **AC-2:** Скачанный по умолчанию `stickers-cut-...svg` содержит только контуры резки стикеров и не содержит режущихся крестов меток совмещения.
3. **AC-3:** В SVG присутствует корневой узел с размерами страницы и опорный габарит листа.
4. **AC-4:** В блоке «Метки совмещения» в UI отображаются расстояния между реперами, пересчитываемые при смене формата/ориентации.
5. **AC-5:** При установке Bleed = 2 мм и зазоре 1 мм отображается предупреждение о необходимости зазора от 4 мм.
6. **AC-6:** Все unit-тесты (включая новые) проходят успешно (`npm test`), сборка завершается без ошибок (`npm run build`).

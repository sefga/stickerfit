## 2. Архитектура решения

### 2.1 Маскирование формы в PDF
Вместо прямой вставки прямоугольного `embeddedImage` для каждого круглого стикера создается предварительно маскированный Canvas нужного размера (300 DPI) с альфа-каналом:
```typescript
// При circle:
ctx.beginPath();
ctx.arc(cx, cy, radius, 0, Math.PI * 2);
ctx.clip();
ctx.drawImage(rawImage, ...);
```
Полученный PNG с прозрачностью за пределами круга встраивается в PDF ровно 1 раз через `pdfDoc.embedPng()`, и тиражируется по всем ячейкам листа.
Результат: **круглый стикер с чистыми полями** без лишних квадратных углов.

### 2.2 Разделение меток печати и контуров резки
- В **PDF для принтера**: метки совмещения по 4 углам листа отрисовываются всегда при включенном чекбоксе «Метки совмещения».
- В **SVG для плоттера**: метки совмещения по умолчанию **НЕ** включаются (чтобы плоттер не резал мат). Добавлен чекбокс «Резать метки на плоттере» (для тех редких случаев, когда нужно прорезать реперы).
- Добавлен экспорт «Калибровочный шаблон реперов (SVG)» для рисования ручкой на прозрачной пленке.

### 2.3 Калибровочные расстояния
Для текущего листа (например, А4 $210 \times 297$ мм при отступе 8 мм):
- $DistX = \text{pageWidthMm} - 16\text{ мм}$ (для Landscape: $297 - 16 = \mathbf{281.0\text{ мм}}$)
- $DistY = \text{pageHeightMm} - 16\text{ мм}$ (для Landscape: $210 - 16 = \mathbf{194.0\text{ мм}}$)
Отображаются в инфо-блоке: «Измерьте линейкой расстояние между центрами крестов на отпечатке: 281.0 × 194.0 мм».

### 2.4 Валидация зазоров Bleed
Если `bleedMm > 0` и $(\text{gapX} < \text{bleedMm} \times 2 \lor \text{gapY} < \text{bleedMm} \times 2)$:
Отображается предупреждение:
*«При вылете ${bleedMm} мм минимальный рекомендуемый зазор — ${bleedMm * 2} мм, чтобы зоны вылетов соседних наклеек не перекрывались.»*

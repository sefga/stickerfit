# Quickstart Validation Guide: Тестирование предпросмотра и устранения лагов

## Сценарии ручной проверки

### 1. Проверка горизонтального и вертикального фото
1. Открыть приложение в браузере (`npm run dev`).
2. Загрузить горизонтальное фото (например, 1920×1080).
3. Проверить режим по умолчанию: фото должно быть аккуратно кадрировано по центру без искажений лиц/объектов.
4. Переключить на «Вписать целиком»: фото должно полностью отображаться с белыми полями сверху/снизу без сжатия по ширине.
5. Нажать «Взять пропорции фото»: стикер мгновенно принимает точные пропорции 16:9, рамка и фото идеально совпадают.
6. Включить «Автоповорот 90°»: фото и ячейки поворачиваются синхронно, без сплющивания.

### 2. Стресс-тест производительности (Устранение лагов)
1. Установить тираж: 80 стикеров (микронаклейки 20×20 мм).
2. Зажать клавишу изменения ширины стикера или быстро двигать ползунки.
3. Открыть Chrome DevTools Performance/Elements:
   - Объем DOM SVG: должен содержать один тег `<defs><image ... /></defs>` и легкие теги `<use ... />`.
   - Время перерисовки кадра: < 16 мс.
   - Зависания вкладки: 0 фризов.

### 3. Проверка форматов и адаптивности листа
1. Переключить формат бумаги на PeriPage 57 мм (термолента) и Альбомный A4.
2. Лист должен целиком помещаться в окне предпросмотра без обрезания краев.

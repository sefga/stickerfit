# Спецификация: 004-plotter-sheet-cut-frame

## Название фичи
**Включение внешней рамки листа (Sheet Cut Frame) в SVG экспорт контура резки для точной фиксации (0,0) по углу листа в плоттерных программах и расчет параметров для стикера 35.4 мм**

## 1. Проблема и контекст
Пользователь использует рулонный плоттер **Mimaki CG-61** (без оптических датчиков) на кэрриер-мате А3 в связке с программой **Easy Cut Studio 6**.
При экспорте контура резки в SVG ранее габарит листа задавался невидимым прямоугольником с `stroke="none" fill="none"`.
Плоттерные программы (Easy Cut Studio, Silhouette Studio и др.) игнорируют невидимые векторы без обводки. В результате:
1. Габарит импортированного макета сужается до Bounding Box самих стикеров (например, начинается с отступа 15.6 мм, а не с 0.0 мм).
2. Начало координат $(0,0)$ в плоттерной программе привязывается к крайнему левому стикеру, а не к физическому углу листа А4.
3. Пользователь не может физически пристрелить нож плоттера к углу листа А4 на мате А3, из-за чего возникает смещение всего макета.
4. Пользователь хочет видеть и прорезать внешнюю границу листа точно так же, как и контуры стикеров.

## 2. Пользовательские сценарии (User Stories)

### US-1: Физическая привязка (0,0) к углу листа А4 в Easy Cut Studio
Как оператор плоттера Mimaki CG-61, я хочу, чтобы SVG файл контура резки содержал реальную прорезаемую рамку листа (Sheet Cut Frame), чтобы Easy Cut Studio устанавливала нулевую точку $(0,0)$ строго в угол листа А4, а не в край первого стикера.

### US-2: Управление включением рамки листа в интерфейсе
Как пользователь, я хочу иметь переключатель (чекбокс) «Включать рамку листа в контур резки», включенный по умолчанию, с возможностью его отключения при необходимости.

### US-3: Четкая отрисовка рамки листа в шаблоне для плоттерной ручки
Как оператор плоттера, я хочу, чтобы при экспорте шаблона реперов для плоттерной ручки внешняя граница листа вычерчивалась сплошной линией на прозрачной пленке / мате, чтобы можно было точно вложить лист бумаги А4 по контуру.

### US-4: Точные параметры раскладки для круглых стикеров 35.4 мм
Как пользователь, я хочу получить проверенные полиграфические параметры для стикеров диаметром 35.4 мм (раскладка на А4, зазоры, вылеты, поля, количество на листе).

## 3. Функциональные требования (FR)

- **FR-001**: Функция `generateStickerCutSvg` должна поддерживать опцию `includeSheetBorder?: boolean` (по умолчанию `true`). При значении `true` в векторный контур резки `<g id="CutContour">` добавляется прямоугольник `<rect id="SheetBorder" x="0" y="0" width="${pageWidthMm}" height="${pageHeightMm}" />`.
- **FR-002**: Состояние приложения `AppSettings` и `AppState` расширяется полем `cutSvgIncludeSheetBorder: boolean` (по умолчанию `true`), с сохранением в `LocalStorage`.
- **FR-003**: В интерфейс `index.html` (секция «5. Полиграфия и резка») добавляется чекбокс `#cutSvgIncludeSheetBorder` («Включать рамку листа в файл резки»).
- **FR-004**: В `generateRegistrationTemplateSvg` рамка листа `<rect id="PageBoundary">` переводится с пунктира `stroke-dasharray="2,2"` на непрерывный вектор `stroke="#000000" stroke-width="0.25"` для чистого вычерчивания плоттерной ручкой.
- **FR-005**: Добавлены локализации (RU/EN) для нового чекбокса и подсказок.
- **FR-006**: Unit-тесты для `svgCutGenerator.ts` должны проверять наличие рамки листа по умолчанию, её отсутствие при `includeSheetBorder: false`, и генерацию рамки в шаблоне.

## 4. Критерии приемки (Acceptance Criteria)

- **AC-1**: Экспортированный по умолчанию SVG содержит `<rect id="SheetBorder" x="0" y="0" width="..." height="..." />` внутри группы резки `<g id="CutContour" stroke="..." stroke-width="..." fill="none">`.
- **AC-2**: Bounding Box всего SVG в Easy Cut Studio точно равен размеру страницы ($297.0 \times 210.0$ мм в альбомной ориентации).
- **AC-3**: Снятие чекбокса `#cutSvgIncludeSheetBorder` исключает `SheetBorder` из SVG.
- **AC-4**: Все существующие тесты (119 тестов) и новые тесты проходят успешно (`npm test`).
- **AC-5**: Сборка `npm run build` проходит без ошибок TypeScript и Vite.

## 2. Архитектурное решение и модель рендеринга
В стандарте PDF рендеринг страницы выполняется в порядке появления операторов в content stream:
1. **Слой Underlay (Векторный контур реза)**:
   Для каждого стикера сначала вызывается `page.drawSvgPath(contourPath, ...)`.
   Это записывает векторные операторы пути и цвета штриха `1 0 0 RG ... S` в content stream страницы.
2. **Слой Content (Растровое изображение стикера)**:
   Затем вызывается `page.drawImage(embeddedImage, ...)`.
   Это помещает оператор вызова XObject изображения `q ... /Im1 Do Q`.
   Растровое изображение с вылетом (bleed) перекрывает нижележащий векторный контур.
3. **Слой Overlay (Служебные типографские метки)**:
   Метки реза (`drawCutMarksOnPdf`) и оптические метки совмещения (`drawRegistrationMark`) вызываются после цикла стикеров, оставаясь поверх всех элементов для визуального контроля и считывания камерой плоттера.

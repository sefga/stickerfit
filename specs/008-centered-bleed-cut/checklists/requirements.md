# Контрольный список требований: 008-centered-bleed-cut

## 1. Полнота и непротиворечивость требований
- [x] **CH-01**: Проблема люфта плоттерной резки и компенсации точности сформулирована однозначно.
- [x] **CH-02**: Номинальный размер реза $D$ строго отделён от внутреннего размера арта $D - 2B$ и внешнего вылета $D + 2B$.
- [x] **CH-03**: Определено поведение по умолчанию (`bleedCenterCut = false`) для сохранения обратной совместимости.
- [x] **CH-04**: Прописана защита от схлопывания картинки на малых размерах ($\le 40\%$ инсет).

## 2. Проверяемость и трассируемость
- [x] **CH-05**: Каждое функциональное требование (FR-01 ... FR-08) имеет четкий метод программной верификации.
- [x] **CH-06**: Все критерии приемки (AC-01 ... AC-05) измеримы в физических миллиметрах и покрываются автоматическими тестами.
- [x] **CH-07**: Плоттерный векторный контур изолирован от визуального масштабирования растра.

## 3. UI и локализация
- [x] **CH-08**: Элемент управления (чекбокс) виден только при осмысленном состоянии вылета (`bleedMm > 0`).
- [x] **CH-09**: Тексты и подсказки подготовлены на русском и английском языках.
